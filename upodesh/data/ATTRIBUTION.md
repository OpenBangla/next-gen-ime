# Data provenance and licensing

Bangla.gov.bd resources (EBLICT/BCC): BDNC, `banglagov` Hugging Face models,
Digital Lexicon etc. were reviewed. Their `/api` endpoints require
authentication and no public bulk download is available from them today, so
nothing from bangla.gov.bd is vendored here. Contact pdeblict@bcc.net.bd /
`/bn/service-request` if licensing for research use needs to be cleared.

- `openbangla-keyboard/data/dictionary.json` — submodule, upstream license.
- Roman-form generation uses [dhoni](https://github.com/OpenBangla/dhoni) (MIT) via a git dependency (pinned; Khipro mode/variants tracked in [OpenBangla/dhoni#1](https://github.com/OpenBangla/dhoni/pull/1), fork `MuntasirSZN/dhoni@34a2116` until merged; adds nukta folding, canonical `ঋ`/`ৃ` → `ri`, and Avro inherent-vowel/aspiration spelling variants).
- `frequency.json` — **IndicCorp V2** (CC-0; `ai4bharat/IndicCorpV2`, HF).
  Generated by `generate/src/bin/corpus-count.rs` from `bn.txt`
  (sha256 `a5b0ec3df504ebcadf551249c6dc53c9ab17112739aedfa861b52e6b7b2f2d6d`);
  covers 99,422 / 159,384 dictionary words (62.4%) from 922M tokens.
  Citation: Doddapaneni et al., *Towards Leaving No Indic Language Behind*,
  ACL 2023.
- `khipro-testcases.tsv` — KhiproTeam Khipro layout test corpus, synced with [rank-coder/khipro-m17n](https://github.com/rank-coder/khipro-m17n) (MIT, © 2024 rank_coder) for the `f`, `........` and `,,,,,,,,` rows; provided by the `data/khipro-m17n` git submodule (used as regression vectors only).
- `lemma.json` — lemma/POS metadata **derived from bnwiktionary** (CC BY-SA 4.0),
  via `generate/extract_lemma.py` (dump `bnwiktionary-latest-pages-articles-multistream.xml.bz2`,
  downloaded 2026-11-08, sha256 `ef0d6c16e480bf6ef8c81cfd39bee37cf24e480bb46dfc267ae2b593de8d71b6`).
  63,556 entries (word→POS: noun/adj/verb/...). Derived facts only; attribution:
  bnwiktionary contributors, licensed under CC BY-SA 4.0.
- `weights.json` — error-class distribution from `generate/train_weights.py`
  (40,000 pairs sampled seed=42 from the CC-0 IndicCorp corpus, pairs sha256 `6675e901…`);
  a config artifact for future `EditCosts` wiring. CC-0-clean.
- `eval/banglasec-test.csv.gz` — [mehedihasanbijoy/BanglaSEC](https://huggingface.co/datasets/mehedihasanbijoy/BanglaSEC) test split (MIT, official DPCSpell splits, sha256 `a3397183263129109b63c473f0f81d082f45d7bf3e86e47c290044af655bd158`). Eval-only; never used for training, never ship typos. Computed results: Top-1 18.4% / Top-5 23.2% on 177,919 pairs.
- Error operators in `generate/gen_errors.py` follow the taxonomy of habibsifat's Bengali error generator (reference-only, no license stated upstream → tables not copied verbatim; data derived from the vendored IPA table + keyboard geometry).
